
# Customer Orders and Retention Analysis

An interactive data analytics portfolio project built with Python to explore customer orders, sales trends, delivery performance, returns, cancellations, and repeat purchasing.

## 🚀 Live Dashboard

[Open the Interactive Streamlit Dashboard](https://customer-orders-retention-analysis-7r6cbx3pri72fmefjzteye.streamlit.app/)

## 📌 Project Overview

This beginner-friendly project demonstrates data cleaning, exploratory data analysis (EDA), KPI tracking, data visualization, and interactive dashboard development using synthetic practice data.

## 🛠️ Technologies

- Python
- pandas
- SQLite SQL
- Matplotlib
- Plotly
- Jupyter Notebook
- Streamlit

## 📊 Dashboard Features

- Order, delivery, return, and cancellation KPIs
- Monthly sales trend analysis
- Product category performance
- City-level sales analysis
- Sales channel comparison
- Customer repeat-purchase analysis
- Interactive filters and scenario simulator

## 📁 Project Structure

- `app.py` — Streamlit dashboard application
- `Customer_Orders_and_Retention_Analysis.ipynb` — Analysis notebook
- `data/` — Sample datasets
- `requirements.txt` — Python dependencies
- `run_dashboard.bat` — Windows launch script
- `README.md` — Project documentation

## ▶️ Run Locally

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Install the required packages:

   `python -m pip install -r requirements.txt`

4. Launch the dashboard:

   `python -m streamlit run app.py`

5. Open the local URL shown in your terminal.

## ⚠️ Dataset Disclaimer

All records are synthetic practice data created for learning and portfolio demonstration. They do not represent real customers, a real company, or verified business performance. Monetary values use unspecified sample currency units, not BDT.
